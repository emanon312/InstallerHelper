InstallerHelper —— 把软件装到你指定的目录
==========================================

为什么需要它
------------
很多安装包（尤其是 electron-builder 打的 NSIS 包）界面里根本不给选目录，
直接就往 C 盘塞。这个工具从命令行层面把目录指过去，再顺手把 AppData 里的
配置也搬到 D 盘。


怎么用
------
1. 双击 InstallerHelper.exe（用源码的话是 Start-InstallerHelper.cmd）
2. 把安装包拖进上面的框（exe / msi / msix），也可以点框选文件
3. 目录自动填好 D:\我的应用\<软件名>，想改就改
4. 想把配置也搬走：勾上"把配置数据也搬到 D 盘"
5. 点"开始安装"


装完之后
--------
· 自动找主程序，建桌面 / 开始菜单快捷方式（在"高级选项"里可关）
· 如果安装器不听话装到了别处，会问你要不要迁回你指定的目录
· 配置目录一般要等软件跑过一次才出现，第一次没搬到就再点一次


高级选项
--------
· 把软件目录迁到 D 盘：给已经装好的软件搬家
· 重定向软件的数据目录：扫 %APPDATA% / %LOCALAPPDATA% / %USERPROFILE%，
  勾中要搬的目录，搬走并在原位置留链接


原理与注意
----------
· 迁移用的是目录联接（junction），软件感知不到，照原路径读写
· 卸载前先把链接还原成真实目录，否则卸载器可能连 D 盘的副本一起删
· 部分安装器（如某些 MSI）吃不动 /D=，这时会在装完后检测并询问是否迁移
· 需要装到系统目录时用管理员身份运行

----

helper-core.ps1            识别安装器 / 静默安装 / 迁移 的逻辑
